# Something Special.exe

یک دعوت‌نامه تعاملی فارسی با ترکیب طراحی عاشقانه و شوخی‌های برنامه‌نویسی؛ ساخته‌شده با HTML، CSS و JavaScript مستقل.

## اجرا

به دلیل استفاده از JavaScript ES Modules، پروژه را از طریق یک وب‌سرور محلی اجرا کنید (باز کردن مستقیم `index.html` با `file://` ممکن است در بعضی مرورگرها ماژول‌ها را مسدود کند).

### Python
```bash
python -m http.server 8000
```
سپس به آدرس `http://localhost:8000` بروید.

### VS Code
از افزونه Live Server استفاده کنید و `index.html` را با آن اجرا کنید.

## انتشار روی GitHub Pages

این پروژه در پوشه `Something-Special/` مخزن سایت شخصی قرار می‌گیرد و از مسیر زیر در دسترس خواهد بود:

`https://mzulfikari.github.io/Something-Special/`

## ساختار

- `index.html`: پوسته اصلی برنامه
- `assets/css/`: استایل پایه، اجزا و انیمیشن‌ها
- `assets/js/app.js`: کنترل جریان و رندر مراحل
- `assets/js/state.js`: وضعیت متمرکز برنامه
- `assets/js/calendar.js`: توابع تقویم شمسی
- `assets/js/animations.js`: افکت‌ها و انیمیشن‌ها
- `assets/js/telegram.js`: مرز اتصال آینده به API امن
- `assets/js/utils.js`: توابع عمومی

## اعلان تلگرام

در این نسخه هیچ توکن یا درخواست مستقیمی به Telegram Bot API از مرورگر وجود ندارد. برای فعال‌سازی در آینده، یک endpoint سمت سرور یا Serverless Function بسازید و مقدار `NOTIFICATION_ENDPOINT` را در `assets/js/telegram.js` تنظیم کنید. endpoint باید ورودی‌ها را اعتبارسنجی کند، rate limit داشته باشد و فقط اطلاعات ضروری را ارسال کند.

## نکات

- تاریخ‌ها بر اساس تقویم جلالی و ساعت محلی دستگاه مرورگر هستند.
- پاسخ منفی و پاسخ نیاز به فکر کردن مسیرهای مستقل و محترمانه دارند.
- اطلاعات انتخابی فقط در حافظه همان نشست نگهداری می‌شوند و به سرور ارسال نمی‌شوند.
- فونت‌ها از Google Fonts بارگیری می‌شوند؛ در صورت نبود اینترنت از فونت جایگزین استفاده می‌شود.
